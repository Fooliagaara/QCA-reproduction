# Experiment artifacts

Includes 64-frame indices for 1337 LongVideoBench validation questions and 2700 Video-MME questions, per-question predictions, and execution logs. Video-MME predictions were recovered from logs; `recovered_from_log` records this provenance. Original videos, annotations, model weights and approximately 15 GB of frame features/ITM intermediates are not included.

Prediction directories were named `longvideobench_full` and `videomme_full` on the server at export time. Paths in older instructions may differ.
